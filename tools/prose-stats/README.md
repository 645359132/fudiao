# 文风统计（prose-stats）

对导出的 TXT 算一套能量化“AI 味”的数字（需求 B87），改写手、技能与审核之前先在作者的书上记下基线，改后再跑一遍比较。数字由 `packages/writing/src/style.ts` 算，写手每章拿到的风格账本、审核的文风检查用的是同一套函数。

```bash
pnpm prose:stats D:\书\长夜问刀.txt --names 沈孤舟,楚晚晴 --json m8/baseline.json
```

```bash
pnpm prose:stats D:\书\长夜问刀-改后.txt --names 沈孤舟,楚晚晴 --compare m8/baseline.json
```

- `--names`：人物、地点、物品的名字（逗号分开），不算进高频词与句首模板；不给时名字会占满高频词表。
- `--json`：把数字存成 JSON，`--compare` 与之前的一份并排给出差值；`--top` 各表列多少行（默认 40）。
- 拆章：认“第N卷 卷题”“第N章 章题”，也认复调导出时章名单独一行、前面空一行、段落全角缩进的写法；拆不出章时整篇算一章。

报告各节：总览（章数、字数、每章字数的均值与标准差、对话占比、叙述句长与段落长的变异系数、MTLD）、章名字数分布、对话占比（分卷与最低十章）、章尾方式、高频实词（对白与名字以外的二到四字片段，去掉含虚字的）、句首模板（以名字开头的记名字加两个字）、跨章重复的片段（四字及以上，按出现的章数）。

指标的依据见 `IMPLEMENTATION_PLAN.md` 的“M8 的依据”；《长夜问刀》的基线见 `m8/PROSE.md`。只读文件，不把原文写进任何地方。
